# AI剪贴板助手 - 实现方案

## 技术选型
- **前端**: React + TypeScript + Tailwind CSS（现代化UI）
- **后端**: Rust + Tauri（高性能、体积小、安全）
- **LLM**: 兼容OpenAI格式的API（支持本地Ollama、OpenAI、Azure等）
- **剪贴板**: 使用Tauri的剪贴板API
- **全局热键**: Tauri的globalShortcut API

## 核心功能实现

### 1. 系统托盘（复用现有实现模式）
- 使用ctypes调用Windows API实现托盘图标
- 右键菜单：显示设置、复制翻译结果、复制总结、退出
- 开机自启功能（通过注册表）

### 2. 剪贴板监听
- 监听剪贴板变化（SetClipboardViewer或Tauri API）
- 支持文本、图片、文件
- 去重和防抖（避免频繁触发）

### 3. 全局热键
- Ctrl+Shift+V: 触发翻译
- Ctrl+Shift+S: 触发总结
- 可自定义快捷键

### 4. LLM集成
- 支持多种LLM提供商配置
- Prompt模板：翻译/总结专用
- 流式响应显示

### 5. UI界面
- 悬浮窗显示翻译/总结结果
- 可折叠、可调整大小
- 支持一键复制结果

## 实现步骤
1. 创建Tauri项目框架
2. 实现系统托盘功能（参考todo-reminder实现）
3. 实现剪贴板监听和全局热键
4. 集成LLM API调用
5. 开发UI界面（悬浮窗 + 设置页面）
6. 添加配置持久化（JSON配置文件）
7. 测试和优化

## 配置文件格式
```json
{
  "llm": {
    "provider": "openai",
    "apiKey": "",
    "baseUrl": "https://api.openai.com/v1",
    "model": "gpt-3.5-turbo"
  },
  "hotkeys": {
    "translate": "Ctrl+Shift+V",
    "summarize": "Ctrl+Shift+S"
  },
  "features": {
    "autoTranslate": true,
    "autoSummarize": false,
    "showPopup": true
  }
}
```
