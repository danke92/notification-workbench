# 待办提醒（Windows 桌面小部件）

单文件 Python + tkinter，零第三方依赖，黑黄配色 + 微软雅黑加粗。
数据保存在 `~/.todo_reminder/tasks.json`，重启不丢失。

## 主界面（极简）

无边框桌面小部件，只显示事项列表：

- **顶部细条**：按住可拖动窗口（位置自动记忆）；右侧「⚙」打开设置面板，「✕」收进托盘
- **列表**：✔ 完成标记 / 任务内容 / 时间（重复任务显示「每天 09:00」式简写）
- **右键任务**：完成（重复任务=顺延）/ 编辑 / 立即提醒 / 删除；双击=编辑

## 设置面板（点 ⚙ 打开）

- **添加任务**：一行智能输入，回车即添加
  ```
  明天9点 交报告 #工作     30分钟后 站会     喝水 每天9点
  周五 交周报   10-20 14:00 复查   10月21日 交房租   买菜
  ```
  时间：`HH:MM` `9点` `9点半` `今天/明天/后天X点` `N分钟后` `N小时后` `N天后` `周X`
  `X月X日` `MM-DD` `YYYY-MM-DD`；分类：`#标签`

- **重复事项**（提醒后自动顺延到下一次）：
  ```
  喝水 每天          起来活动 工作日9点      健身 每周一三五20:30
  写周报 每周五      复盘 每3天 / 每隔3天    喝水 每隔2小时
  ```
  `每天`（每天同一时刻）· `工作日`（跳过周末）· `每周` / `每周X` /
  `每周一三五`（指定星期几组合）· `每月` · `每隔N天` · `每隔N小时`
  只写重复不写时间时，从当前时刻起算第一次提醒；编辑框的「重复」栏也可
  手动填这些写法
- **选中任务**：完成 / 编辑 / 删除 / 提醒
- **显示筛选**：全部 / 进行中 / 已完成 × 分类
- **常驻桌面**：📌 置顶开关 · 🚀 自启开关 · 💤 收进托盘 · ⏻ 退出程序
- **Esc** 关闭面板

## 常驻桌面

- 默认置顶；点 ✕ / 最小化收进系统托盘（黄色感叹号图标），左键唤回、右键菜单同款开关
- 默认开机自启（注册表 HKCU Run），设置面板或托盘菜单可关；关过一次不再自动打开
- 重复启动只提示，不会开第二个实例

## 提醒

- 到点弹 Windows 通知 + 提示音（Toast 失败退回置顶弹窗；启动补发错过的提醒）
- 重复任务（每天/工作日/每周/指定星期/每月/每隔N天/N小时）提醒后或点完成后
  自动顺延下一次；关机几天再开直接顺延到未来，不会堆积过期提醒

## 命令行

```
python todo_reminder.py --selftest   核心逻辑自测（36 项断言）
python todo_reminder.py --smoke      GUI 冒烟测试
python todo_reminder.py --data PATH  指定数据文件
```

## 常见问题

- **窗口找不到了？** 看右下角托盘黄色感叹号图标，点一下
- **收不到通知？** 检查 Windows「专注助手」；Toast 失败会退回置顶弹窗
- **改字体/颜色？** 代码顶部 `FONT` 与 `C_*` 常量
