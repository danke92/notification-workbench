# 蛋壳egg 的个人主页 🥚✨

深色蒸汽波 / Y2K 风格的个人网站，纯 HTML / CSS / JavaScript 手写，零依赖。

**在线访问**：https://danke92.github.io/personal-website/

## 页面结构

| 文件 | 内容 |
|---|---|
| `index.html` | 主页：首屏 / 关于我 / 技能 / 项目 / 博客预览 / 联系 |
| `blog.html` | 博客列表 |
| `blog-post.html` | 文章模板页 |

## 怎么改内容

见 [使用说明.md](./使用说明.md)。最快的方式：打开网页点右下角「✏️ 编辑内容」，直接点文字修改，保存下载替换即可。
