# 个人网站 · 使用说明

纯静态站点，无需安装任何东西。所有占位内容都标了 `<!-- ★ 修改：... -->` 注释，用编辑器搜索 `★` 或 `你的名字` 就能定位所有要改的地方。

## 一、本地预览

- **最简单**：直接双击 `index.html`，浏览器打开即可。
- **更正规**（推荐，地址栏是 http:// 开头）：在本目录运行 `python -m http.server 8765`，然后访问 http://127.0.0.1:8765/index.html 。

## 二、文件结构

| 文件 | 作用 |
|---|---|
| `index.html` | 主页：首屏、关于我、技能、项目、博客预览、联系 |
| `blog.html` | 博客列表页 |
| `blog-post.html` | 文章模板页（写新文章时复制它） |
| `css/style.css` | 全部样式，顶部 `:root` 是主题色配置 |
| `js/main.js` | 交互脚本，顶部是打字机文字配置 |
| `js/editor.js` | 网页编辑模式（右下角 ✏️ 按钮） |
| `assets/avatar.svg` | 占位头像 |
| `assets/favicon.svg` | 浏览器标签页小图标 |

## 三、内容替换的两种方式

### 方式 A：后台登录后直接编辑（推荐，零代码）

1. 浏览器打开网站根目录下的 **`admin.html`**（例如 `http://127.0.0.1:8765/admin.html` 或上线后的 `https://你的地址/admin.html`）；
2. 输入后台密码（默认 **`egg2026`**），点「进入」后自动跳回网站，右下角出现编辑工具条；
   - ★ 想改密码：打开 `admin.html`，改顶部 `ADMIN_PASSWORD = '...'` 那一行即可；
   - 「退出后台」按钮可随时隐藏编辑工具条（只影响你当前的浏览器）；
3. 点「✏️ 编辑内容」，页面文字出现青色虚线框，直接点击修改：名字、介绍、技能、项目、文章标题摘要、联系方式……都能改；
4. 编辑模式下点链接不会跳转，放心改；
5. 改完点「💾 保存并下载」，浏览器会下载一个同名 html 文件；
6. 用下载的文件**替换网站文件夹里的同名文件**，再按本文「五、部署上线」更新（或运行 `python upload-github.py danke92 personal-website`），刷新即可看到效果。

> 注意四点：编辑模式只在浏览器里生效，**必须下载替换原文件并重新上传**才算真正保存；普通访客看不到任何编辑按钮；更换头像图片、新增/删除整个项目或文章卡片、修改打字机轮播文字，仍需用方式 B；哪个页面就下载哪个文件（主页改完下载 index.html，博客列表改完下载 blog.html）。

### 方式 B：直接改文件（进阶）

想改什么 → 打开哪个文件 → 搜什么关键词：

| 想改什么 | 文件 | 怎么改 |
|---|---|---|
| 你的名字（标题栏/导航/首屏/页脚） | `index.html`、`blog.html`、`blog-post.html` | 搜索 `你的名字`，全部替换 |
| 首屏打字机轮播的文字 | `js/main.js` | 顶部 `TYPING_TEXTS` 数组，改引号里的词 |
| 一句话自我介绍 | `index.html` | 搜索 `这里放一句你的自我介绍` |
| 头像 | `assets/` + `index.html` | 把你的照片放进 `assets/`，再把 `avatar.svg` 改成照片文件名（如 `avatar.jpg`） |
| 坐标 / 身份 / 邮箱 | `index.html` | 搜索 `待替换` 和 `you@example.com` |
| 关于我的段落 | `index.html` | 搜索 `我是一名开发者`，下方几段随便写 |
| 统计数字（几年经验/几个项目…） | `index.html` | 搜索 `data-count`，改数字和下方文案 |
| 技能标签 | `index.html` | 搜索 `skill-chips`，每个 `<span class="chip">` 是一个标签 |
| 项目卡片 | `index.html` | 搜索 `★ 项目卡片模板`，复制整个 `<article>` 改内容；多余的卡片整块删掉 |
| 社交链接（GitHub/掘金/知乎…） | `index.html` | 搜索 `social-pill`，把 `href="#"` 换成你的链接 |
| 联系邮箱 | `index.html` | 搜索 `you@example.com` |
| 博客列表新增一行 | `blog.html` | 搜索 `★ 文章行模板`，复制一个 `<a class="post-row">` 改标题、日期、标签 |
| 写一篇新文章 | `blog-post.html` | 复制整个文件改名（如 `post-1.html`），改 `<title>` 和正文，再回 `blog.html` 把某一行链接指向它 |
| 主题颜色（青色→其他色） | `css/style.css` | 顶部 `--accent: #22d3ee` 换成你喜欢的色值 |
| 页脚备案号（国内部署才需要） | `index.html` | 搜索 `ICP`，取消注释并填备案号 |

## 四、写文章的排版元素（blog-post.html 里都有示例）

- 小标题：`<h2>…</h2>`（带左侧色条样式）
- 引用：`<blockquote>…</blockquote>`
- 行内代码：`<code>…</code>`
- 代码块：复制页内 `code-window` 那个 `<div>`，改 `<pre>` 里的代码（`<` 要写成 `&lt;`）

## 五、部署上线（免费方案）

**GitHub Pages（推荐）**
1. 注册/登录 GitHub，新建一个仓库（名字随意）；
2. 把本文件夹全部文件上传到仓库（可用 GitHub 网页端拖拽上传，或用 git 命令）；
3. 仓库 Settings → Pages → Source 选 `main` 分支，保存；
4. 一两分钟后，`https://你的用户名.github.io/仓库名` 即可访问。仓库名设为 `用户名.github.io` 可以直接用根域名。

**Vercel / Netlify**：注册后把 GitHub 仓库导入，一键部署，还会送 HTTPS 和预览域名。

国内服务器 + 自有域名部署的话需要 ICP 备案，备案号加在页脚（见对照表最后一行）。

## 六、两个小提醒

- 改完保存后刷新浏览器即可看到效果；如果样式没生效，按 `Ctrl + F5` 强制刷新（清缓存）。
- 不熟悉 HTML 也没关系：只改文字、别动标签（尖括号包着的部分），就不会坏。
