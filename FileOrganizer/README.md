# 文件整理助手

一个绿色、安全、可撤销的 Windows 文件夹整理工具。它只移动文件，从不删除或改写文件内容。

## 功能

- 一键把文件夹里的文件按 **类型**（图片 / 文档 / 视频 / 音频 / 压缩包 / 程序与安装包 / 代码与配置 / 字体 / 其他）或 **修改日期**（如 `2026-09`）整理到子文件夹，也可以“类型 + 日期”两级分类
- **预览模式**：先查看移动计划，确认后再执行（默认开启）
- **一键撤销**：每次整理都有记录，随时恢复原状
- 重名文件自动加编号（`报告.pdf` → `报告 (1).pdf`），不会覆盖
- 自动跳过隐藏 / 系统文件（`desktop.ini`、`Thumbs.db`、`.` 开头的文件等）
- 可选包含子文件夹；已经分类过的文件夹不会被重复整理
- 分类规则可通过 `config.json` 自定义

## 使用方法

1. 双击桌面或开始菜单中的 **文件整理助手** 快捷方式
2. 选择要整理的文件夹（默认已填好“下载”文件夹）
3. 选择整理方式，保持“预览模式”勾选，点击 **开始整理** 查看移动计划
4. 确认无误后，取消“预览模式”，再次点击 **开始整理** 并确认
5. 整理错了？点击 **撤销上次整理** 即可恢复原状

## 自定义分类

用记事本打开程序目录下的 `config.json`，例如：

```json
{
  "categories": {
    "设计素材": [".sketch", ".xd", ".fig"],
    "图片": [".jpg", ".png", ".webp", ".raw"]
  }
}
```

- 键是分类名（会作为文件夹名），值是扩展名列表（含点、不区分大小写）
- 与默认分类同名的键会**整体替换**该分类的默认规则（如上例“图片”只剩 4 种扩展名）
- 没有匹配到任何分类的文件会进入“其他”
- 修改后重启程序生效

## 命令行用法

```bat
py "%LOCALAPPDATA%\Programs\FileOrganizer\organizer.pyw" --cli "D:\下载" --dry-run
py "%LOCALAPPDATA%\Programs\FileOrganizer\organizer.pyw" --cli "D:\下载"
py "%LOCALAPPDATA%\Programs\FileOrganizer\organizer.pyw" --undo
```

参数：`--mode type|date|type_date`（整理方式）、`--recursive`（含子文件夹）、
`--dry-run`（仅预览）、`--no-dup-rename`（重名跳过）、`--undo`（撤销）。

## 卸载

运行程序目录中的 **卸载.bat**（安装目录：
`%LOCALAPPDATA%\Programs\FileOrganizer`），或手动删除该目录以及桌面、
开始菜单中的“文件整理助手”快捷方式。

## 安全说明

- 程序只移动文件，从不删除或改写文件内容
- 被占用或无权限的文件会自动跳过，并记录在日志中
- 每次整理的撤销记录保存在 `%LOCALAPPDATA%\FileOrganizer\logs`
- 出于安全考虑，磁盘根目录、用户主目录和 Windows 系统目录不允许整理
